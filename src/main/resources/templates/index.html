DevOps-ready WAR application

Project 4 - Tomcat Deployment Demo

WAR-based Spring Boot application prepared for Apache Tomcat 9 on Amazon Linux EC2.

Build Tool Maven
Deployment Target Apache Tomcat 9
Runtime Java 17

Deployment flow

  1. Build the WAR with Maven.
  2. Copy `project4-devops-app.war` to Tomcat `webapps/`.
  3. Start or restart Tomcat on the EC2 instance.
  4. Access the app on port `8080`.
